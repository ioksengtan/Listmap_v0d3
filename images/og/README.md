# Generated Open Graph images

These `images/og/<story_id>.jpg` files are created by `npm run compile-data`
(see `scripts/compile-og-images.js`). Each file is a 1200×630 crop of an
authorized photo already in `images/stories/<story_id>/`.

Do not edit by hand. Source, license, and credit for each photo stay in that
story's `images/stories/<story_id>/CREDITS.md`.
